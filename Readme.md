# Supplementary calculation files / 补充计算文件

## English

This directory accompanies the clean revised manuscript. It contains two clearly separated calculation routes:

- `Euler-Euler Case-UDF/`: the Euler--Euler--DPM source code, initialized calculation file, archive, and Chinese usage note associated with the modelling framework reported in the manuscript.
- `VOF Case-UDF For Open/`: an openly shared volume-of-fluid (VOF) calculation scheme, source code, initialized calculation file, archive, and Chinese usage note. The VOF scheme is an alternative formulation supplied for transparency and reuse; it was not used to generate the Euler--Euler fields discussed in the manuscript.

The same public materials are mirrored at:

https://github.com/Zhenkeaidai/DeC-Si-P-in-Steel-Maker-CFD-work

The detailed mathematical derivations and numerical settings are contained in Appendices A--C of the single integrated manuscript PDF. No separate Appendix PDF is required.

Before submission or reuse, the author should verify that the distributed calculation files, UDF source, manuscript parameter table, and repository release correspond to the intended production version. This package records the supplied files without opening or modifying the Fluent case files.

## 中文

本目录随 clean revised 稿件一并提供，包含两条相互区分的计算路线：

- `Euler-Euler Case-UDF/`：与论文所述建模框架对应的 Euler--Euler--DPM 源代码、初始化计算文件、压缩包及中文使用说明。
- `VOF Case-UDF For Open/`：公开共享的流体体积法（VOF）计算方案、源代码、初始化计算文件、压缩包及中文使用说明。该 VOF 方案作为备选方法提供，用于提高透明度和便于复用；论文讨论的 Euler--Euler 结果并非由该 VOF 方案生成。

相同的公开材料同步镜像于：

https://github.com/Zhenkeaidai/DeC-Si-P-in-Steel-Maker-CFD-work

详细数学推导和数值设置已合并在唯一主论文 PDF 的附录 A--C 中，不再单独提供 Appendix PDF。

提交或复用前，作者仍应核对所分发的计算文件、UDF 源码、论文参数表和 GitHub 仓库版本是否共同对应预期的正式计算版本。本次打包仅记录并复制所提供文件，没有打开或修改 Fluent case 文件。
